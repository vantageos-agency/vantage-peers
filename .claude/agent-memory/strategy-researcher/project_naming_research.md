Conducted on 2026-03-25. Full report at `/root/coding/vantage-memory/docs/naming-research.md`.

**Top picks:**
1. SwarmState (`swarm-state` npm available, GitHub org available, swarmstate.io/.com available, .dev taken)
2. CortexSync (`cortex-sync` npm available, GitHub org available, cortex-sync.dev/.io available, cortexsync.com taken)
3. VantageMemory (current — all vantage-memory npm + vantagememory.com/.dev/.io domains available)

**Why:** "memory" in the current name undersells the full scope (memory + messaging + tasks + diary). SwarmState wins on concept fit.

**Eliminated:** agent-brain, hivemind, agent-hub, agent-mesh, agent-nexus (all npm taken or direct competitor); mindweave (all domains taken, existing product); swarmlink, neuromesh, noosphere, mnemosyne, mindforge (npm taken).

**Key competitive note:** agent-nexus (npm v1.0.9) is a direct competitor — multi-terminal Claude Code communication via MCP/SQLite. Avoid any "agent-" prefix names.

**How to apply:** If user returns to naming or branding questions, SwarmState is the recommended rename. VantageMemory is viable if rename cost is too high.
