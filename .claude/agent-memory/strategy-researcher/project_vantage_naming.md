Conducted 2026-03-25. Full report at `/root/coding/vantage-memory/docs/naming-vantage-alternatives.md`.

**Candidates researched:** VantageMemory, VantageSync, VantageMind, VantageHive, VantageState, VantagePeer, VantageCore, VantageLink, VantageNet, VantageBrain.

**Key findings:**
- ALL 10 npm `vantage-*` names are 404 (free)
- ALL 10 GitHub org handles (PascalCase) are 404 (free)
- `vantagecore.dev` and `vantagecore.io` are DNS-active with live IPs — VantageCore eliminated
- `vantagemind.com` is active: Vantage Mind HK events company (15+ years old)
- `vantagebrain.com` is active: Vantage:Brain GmbH Germany (executive consulting)
- `vantagenet.com` is active: Vantage Networks AU (IT services firm)
- `vantagesync.com`, `vantagehive.com`, `vantagestate.com` are parked/brokered (acquirable)
- `vantagepeer.com`, `vantagelink.com`, `vantagememory.com` are all FREE

**Top 3:**
1. VantageSync — "sync" best signals cross-machine state; .dev/.io free; .com parked on Afternic (~$500-2K)
2. VantageMemory — current name; all domains including .com free; zero migration cost
3. VantagePeer — only other candidate with .com free; strong P2P signal; weaker scope coverage

**How to apply:** Use this when Laurent returns to Vantage-constrained naming decisions. VantageSync is the recommended rename if scope signaling matters. VantageMemory is the keep-it recommendation if migration cost is the priority.
