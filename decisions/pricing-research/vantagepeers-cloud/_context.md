## Product description

VantagePeers Cloud is the hosted SaaS edition of the VantagePeers protocol — persistent memory, messaging, and task management for Claude Code agents and other AI systems via MCP.

The Self-Hosted edition is free + Pro Support paid (€99/year). VantagePeers Cloud removes self-host operations (Convex deploy, env vars, key rotation, monitoring) for users who want zero ops.

## Currently drafted Cloud tiers (to validate via this research)

- **Solo** — €49/year — single-user, all features, "launch price" badge
- **Team** — €290/year — small team (~5 seats), shared workspace, all features
- **Enterprise** — Book a call — custom contracts, SLA, security/compliance addenda
