## Backward compatibility

- Each MCP handler keeps the legacy `?? 20` default at the convex.query call site, so callers that omit `limit` keep the pre-batch page size. Only when `limit` is explicitly provided does the new `clampLimit()` path apply (matches PR #635 contract).
- Each Convex `createdBefore` arg is `v.optional(v.number())`; pre-batch callers never pass it, so they get exactly the pre-batch return.
- No tool removes, renames, or repurposes an existing arg.
- `nextCursor` is added to the envelope only when the returned page is full (rows ≥ requested limit). Callers that ignore `nextCursor` see no behavioral change.
