- **The Client ID Metadata Document deny-list can cover a host or a registrable domain; a hanging domain cools down; DCR refuses URL-shaped client ids.** `oauth:deleteClient` takes `scope: "url" | "host" | "domain"` (default `url`, `/admin/oauth/document-clients/{deny,allow}` accept `scope`): the shared helper `convex/lib/documentClientDenial.ts` asks the exact URL, its host and its registrable domain (tldts, private suffixes included), so another path on a denied host no longer passes at /authorize, /token, refresh and every token reader; a token minted before a host or domain listing stops answering at once (derived at request time, denied not deleted, and a lift restores it). Same door, same audit events, same lift; no new write door. A domain whose fetch timed out answers `503 temporarily_unavailable` (`cooling-down`, no fetch) for 30 s at /authorize and /token, so hanging domains cannot keep the 3-slot authorize pool full; refresh is unaffected. `createClient` and `registerPublicClient` refuse a URL-shaped client_id (`URL_CLIENT_ID_REFUSED`); POST /register and POST /admin/oauth/clients already assign `crypto.randomUUID()`, pinned by a test. rights-derivation: the denial is read live at every token reader, never copied onto a token. Backend contract 26 -> 27. Task k171z3pbydgfb6rp3tpns3a4k18hynws.
- **Sentinel round on the follow-up.** The hanging-document cooldown is keyed by the exact client_id URL (never the registrable domain, so a stranger's timeout on `slow.example.co.uk` cannot refuse `app.example.co.uk`), is armed by /authorize and /token only, and never refuses a refresh; the per-domain in-flight bound stays. `getRefreshTokenByHash`, `getRefreshTokenForGrant` and `rotateRefreshToken` now obey the deny-list like the access reader (null, null, `refused`/`client-denied`, family not revoked so a lift restores it). The URL-shaped refusal is `/^[\s\p{Cc}\p{Cf}]*https?:/iu` and the denial no longer short-circuits on `https://`, whatever the id's shape. The admin answer carries `covers` ("exact URL" | "exact host" | "registrable domain and all subdomains") and, for host and domain scopes, `tokensRefused` (refused at every reader, not revoked; `accessTokensRevoked` stays 0).
