- **The Client ID Metadata Document deny-list can cover a host or a registrable domain; a hanging domain cools down; DCR refuses URL-shaped client ids.** `oauth:deleteClient` takes `scope: "url" | "host" | "domain"` (default `url`, `/admin/oauth/document-clients/{deny,allow}` accept `scope`): the shared helper `convex/lib/documentClientDenial.ts` asks the exact URL, its host and its registrable domain (tldts, private suffixes included), so another path on a denied host no longer passes at /authorize, /token, refresh and every token reader; a token minted before a host or domain listing stops answering at once (derived at request time, denied not deleted, and a lift restores it). Same door, same audit events, same lift; no new write door.
