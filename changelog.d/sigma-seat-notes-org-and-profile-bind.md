- **Seat briefing notes carry their org; admin token revoke answers 404 not 500; deleteClient no longer raises.** VantagePeers Cloud. `briefingNotes:create` takes the transport's `verifiedOrg` (believed from the service account only, resolved to an active mapping, stamped through `withOrgScope`'s member scope), so a one-agent seat's note is stored with its org ID and the seat reads it back; `create_briefing_note` forwards the org from the verified oauthContext, never from an argument, and refuses a non-master bearer whose org cannot be resolved. The fleet master is unchanged (fleet-owned note). New internal door `oauth:bindScopeProfileAgent` binds an agentId onto a seat profile (refuses unless the agent exists, is active and is in the profile's org by stored ID (judged by `resolveActingPrincipal` alone, refusing with its `IdentityRefusalError`; no label fallback)); run with the admin key. `oauth:revokeAccessTokensOnly` raises coded ConvexErrors (`CLIENT_NOT_FOUND`, `REASON_TOO_SHORT`, `INVALID_TARGET`, `TOKEN_NOT_FOUND`) so the route maps 404/400 on `err.data` (a plain Error is redacted to "Server Error" in prod and answered 500), and takes `tokenId` instead of `clientId` to revoke ONE access token by row id (admin-minted `admin-mint:*` tokens have no client row); new master-only route `POST /admin/oauth/access-tokens/:tokenId/revoke`. Root cause of the `DELETE /admin/oauth/clients/:id` 500: `walkClientTokensPage` ran `.paginate` on both token tables in one mutation, which Convex rejects ("multiple paginated queries"); the refresh table now advances by `_creationTime` with `.take`. Evidence: `convex/__tests__/briefingNotesSeatVerifiedOrg.test.ts`, `convex/__tests__/oauthSeatBindAndAdminRevoke.test.ts`, `mcp-server/test/admin-oauth-token-revoke.test.ts`, `mcp-server/test/briefing-note-create-verified-org.test.ts`.
