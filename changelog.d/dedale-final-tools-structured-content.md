- **VantagePeers Cloud and Self-host: the last eight tools return `structuredContent` with a declared output schema (task k171zenmb447qzdqjn7a026b4x8jxzse).** `validate_okf_bundle`, `soft_delete_mission_template`, `add_deployment`, `remove_deployment`, `list_errors`, `get_error`, `validate_task_payload` and `get_repo_mapping` now declare an `outputSchema` and answer a `structuredContent` that is the same object as their text (`list_errors` answers the page form `{ items, nextCursor, truncated }`, cut and declared when a page exceeds the response cap, with the cursor that continues after the last row shown). The text of a success is unchanged; an error or a refusal still carries `isError` and no `structuredContent`. `get_error` answers `{ error: <row> }`, or `{ error: null }` when no entry has that ID, and stays a success there: its text is still `null`. `get_repo_mapping` of a mapping that does not exist is still an error. Additive, so a minor release. Pinned by `mcp-server/test/final-tools-structured-content.test.ts`, which calls each tool through `registerTools`, `validate_okf_bundle`, `soft_delete_mission_template` and `validate_task_payload` included.
