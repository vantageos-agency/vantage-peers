section: Security
---
- **Org lane (missions, templates, mandates, business units, iframe sessions, profiles, rosters, agent registry): the standing is the package's, a cursor is part of the read, and the service-account-only doors say so.** The doors of `missions`, `missionTemplates`, `mandates`, `businessUnits`, `iframeEmbedSessions`, `profiles`, `orgMembership` and `memberWriterRoles` no longer read `scope.isMaster`: the standing comes from `@vantageos/cloud-identity` (`requireStanding`, `requireServiceAccountStanding`, `hasFleetRead`) and the write doors call it directly. `mandates` writes, `missionTemplates:upsert|softDelete`, `orgRoster:getForAccessToken` and `memberWriterRoles:assertPersonMayWrite` refuse through `requireResolvedCaller` (`masterOnly` + `mcpBoundOnly`), so the `RBAC_DENIED` payload names the door and the reason (`no-credential`, `not-mcp-bound-master`). `profiles:getProfile` judges the member's roster by agent ID (the requested label is resolved in the member's own org and judged by `assertPrincipalListed`), not by the legacy name list; a label that names no agent there stays `not-on-roster`. `agents:registerAgent`, `agentRelations:linkChild` and `agentCredentials:mintAgentCredential` stamp the principal's own org (resolved by org ID from the verified session) and no longer consult a second resolver. The cursor anchor (`createdBefore`, the business-units `cursor`) of `mandates:list`, `profiles:listProfiles`, `missions:list` and `businessUnits:list` is now in the index range: with more than 2001 newer rows the old shape (a 2000-row window cut first, filtered after) returned an empty page although older rows existed. `mandates:list` and `missions:list` read a status that no index can range as a bounded fill loop and refuse with `SCAN_CAP_EXCEEDED` rather than return an incomplete page. Doors whose purpose is a whole-fleet reach carry the `fleet-wide:` declaration with its reason; the `allow-local-identity` marker is on four sites that read policy or audit data and one catalog key (list in the PR). Evidence: `convex/__tests__/orgBatchDoors.test.ts` 12/12 (5 red on the previous head), `convex/__tests__/orgBatchCursorInRange.test.ts` 7/7 (5 red on the previous head).
