- **VantagePeers Cloud: station onboarding now puts the new agent on the operator org's roster.** A freshly registered station agent was unreachable by `send_message` ("ne correspond a aucun destinataire de l'organisation") because nothing appended it to the operator org's `client_org_mapping` roster. New internal, append-only, idempotent door `clientOrgMapping:addOperatorRosterMember {agentId}` appends the agent's id and stored name (refuses an inactive agent or one outside the operator org, never removes or reorders). `scripts/mint-station-agents.mjs` compares the org directory by agent ID after the mint, prints `ROSTER_STEP_REQUIRED` with the exact operator command for each unlisted agent and exits 3; `scripts/onboard-orchestrator.sh` prints `ROSTER_STEP_PENDING` and exits 3. No schema, MCP or manifest change. Evidence: `convex/__tests__/operatorRosterAppend.test.ts` (8 tests), `scripts/__tests__/station-credential-scripts.test.mjs`, task k172caqyjb46az1fhbd4vcn9sx8hdr4f.
