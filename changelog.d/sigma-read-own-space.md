- **A memory or episode read without a namespace reads your own space.** `recall`, `text_search`, `hybrid_search`, `list_episodes`, `search_episodes_by_keyword` and `search_episodes_by_semantic`, called with no `namespace` by a non-master session, were refused "requires an explicit namespace argument" (measured on production 2026-11-11, `node scripts/client-seat-matrix.mjs --live`, agent seat probe-a), while the server instructions say an omitted namespace means your own space. These six reads now take the same default as the write side: `registerTools` computes `defaultWriteNamespace(writeSpace)` once per request (whoami's `default_write_namespace`: a person's `team/<org>`, a seat's `orchestrator/<agent ID>`) and `defineTool` fills it in before the read check, so the check runs on it and Convex receives it. The default applies only to a read tool whose namespace is optional: `list_memories` and `export_okf_bundle`, whose namespace names what is listed or exported, still refuse its omission. Nothing widens: a session with no default keeps the refusal, another org's namespace is still refused, the fleet master still reads every namespace.
