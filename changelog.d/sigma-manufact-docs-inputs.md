- **Tool input descriptions say only what a field means; the schema carries its rules.** Across all 92 tools, no field description restates a bound, enum, default or format its schema already encodes (44 restatements removed), and none contradicts its schema (17 fixed). 36 defaults moved from prose into the schema (`default`, same fallback the handler uses). The `fields` parameter is documented per tool: on 14 tools where it changes nothing it stays accepted, marked deprecated and described as having no effect; on 8 tools the description says what `lite` and `full` return. Titles of `set_summary` and the two OKF bundle tools name what they do; `get_task`, `get_briefing_note` and `get_recurring_task` list one consistent set of returned fields. A registry test refuses a description that restates or contradicts its schema. Task k172z2f2q3bgr9wwc3agj08xx98hv4h2 (Manufact documentation 1/2).
