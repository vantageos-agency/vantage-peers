- **VantagePeers Cloud and Self-host: the issue tools return `structuredContent` with a declared output schema (task k171zenmb447qzdqjn7a026b4x8jxzse).** `list_issues`, `get_issue`, `update_issue_status`, `link_commit_to_issue`, `verify_issue` and `issue_stats` now declare an `outputSchema` and answer a `structuredContent` that is the same object as their text (`list_issues` answers `{ count, issues, nextCursor?, truncated? }`, cut and declared when a page exceeds the response cap). The text of a success is unchanged; an error or a refusal still carries `isError` and no `structuredContent`. `get_issue` answers `{ issue: <row> }`, or `{ issue: null }` when no issue matches, and stays a success there: its text is still `{ "error": "Issue not found" }`. Additive, so a minor release. Pinned by `mcp-server/test/issue-tools-structured-content.test.ts`, which calls each tool through `registerTools`, `link_commit_to_issue` and `verify_issue` included.
