- **VantagePeers Cloud: an agent can pause, resume and delete the recurring tasks it created.** `pause_recurring_task`, `resume_recurring_task` and `delete_recurring_task` no longer refuse every non-master caller in the MCP server: they forward the acting agent's verified ID and relay the Convex door's answer unchanged. The door (`convex/recurringTasks.ts` `authorizeScheduleActor`) now reads that agent for a client seat too: a seat reaches Convex as the service account acting for its organisation, whose scope is not master, and the door used to drop the agent and refuse it as a member without a writer role. The creator or the assignee may pause and resume, only the creator may delete, an agent of another organisation or a same-org agent that is neither is refused, and a bearer with no agent proof is refused; the fleet master is unchanged.
