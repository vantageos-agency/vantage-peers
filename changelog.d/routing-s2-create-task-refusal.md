section: Changed
---
- **VantagePeers Cloud and Self-host: an organisation that adopted explicit review routing can no longer assign a task against its own route.** `create_task` takes an optional `repo` (`owner/name`, checked and not stored). For an adopted org, a task naming a repo routed to another owner is refused naming that owner (`RBAC_DENIED`, reason `repo-routed-to-other-owner`); a repo absent from the org's table is refused with "declare it first" (`repo-not-declared`, `add_repo_mapping`); a `[Review]` task, or one tagged `review`, naming a reviewer other than the routed one is refused (`reviewer-not-routed`, `repo-has-no-reviewer`; the row's declared `fallbackReviewer`, the stop-over reviewer, is accepted as well as the primary); the webhook's `createOrUpdateReviewTask` `assignedTo` override is held to the same rule. An org that has not adopted routing is unchanged.
- **A route is compared by agent ID, never by label.** `githubRepoMapping` rows gain optional `orchestratorAgentId`, `reviewerAgentId` and `fallbackReviewerAgentId`; `add_repo_mapping` takes them (the `agentId` list_peers returns), refuses an agent that is not an active agent of the row's org (`route-agent-not-in-org`), and restates them on every update (an update without them clears them). A task's stored assignee ID is compared with the stored IDs; a row with none is refused (`route-has-no-agent-ids`) until it is re-saved with them or stamped by the new migration `migrations/stampRepoMappingAgentIds`, which takes an operator-supplied map of `{ repo, orchestratorAgentId, reviewerAgentId?, fallbackReviewerAgentId? }` (nothing is looked up by name; each ID must be an active agent of the row's org; dry run by default, reversible, lists the repos absent from the input). `getRoute` returns the IDs when stored. Backend contract version 30 to 32: deploy Convex first, the MCP last. The prod guard allow-list gains `run clientOrgMapping:setReviewRoutingAdopted` and the two migration entries, so the operator can adopt an org and stamp its rows after this ships; without adoption none of these refusals fire. rights-migration: existing rows are re-derived by `migrations/stampRepoMappingAgentIds` (dry-run first, listed, reversible); until stamped, an adopted org's route is refused, never widened.
