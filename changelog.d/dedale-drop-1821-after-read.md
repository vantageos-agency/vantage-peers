- **VantagePeers Cloud + Self-host: the after-read scope filters on `list_memories`, `list_episodes`, `get_profile` and `get_fix_pattern` stay, each with the check it still guards.** #1821 (contract 37) moved `memories:listMemories`, `profiles:getProfile` and `fixPatterns:get` to decide the verified org inside the read. A filter is removed only where the door enforces all of it for every caller class, and none of the four qualifies: the memory list door narrows by org while the filter still narrows the org's own team namespace to rows created on the bearer's roster; the profile door checks the organisation's roster (and none for a bearer with no org) while the filter checks the bearer's own, possibly narrower, roster; the fix-pattern door judges a seat by agent ID and then skips `callerIdentities`, while the filter still requires the creator's label on the roster. No behaviour changes. Pinned per caller class (member with a verified org, master, Clerk session, bearer with no org) by `mcp-server/test/after-read-filter-kept-1821.test.ts`.
