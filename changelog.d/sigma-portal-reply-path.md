- **A person is now an addressable recipient for agents of the same org (client portal reply path).** An agent replying to `user:<subject>` is delivered when that person has already written in the agent's own org; a person of another org, an unknown person and the fleet master get one `RBAC_DENIED` (`person-recipient-not-in-org` / `person-recipient-needs-org-agent`). New read `messages:listMyInbox` (the caller's own unread replies, recipient derived from the verified person, never an argument; also via `verifiedPerson`); `messages:markAsRead` accepts a person's own receipts; the generic inbox reads refuse another caller naming a person inbox. The seat path (`seatOrgSlug`) now stamps the seat's org as the tenant and refuses a `from` that is a person or an identity of another org / the fleet (impersonation closed at the Convex door; within-org binding stays with the MCP allow-list). MCP `send_message` keeps a `user:` channel verbatim. Task k1792yz3em7hyw84d765hq71j98ft5h4.
