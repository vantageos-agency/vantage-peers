- **VantagePeers Cloud: a person seat writes (claude.ai, ChatGPT, any MCP client).** A person connected without an agent was refused `PERSON_NO_HUMAN_DOOR` on `store_memory`, `store_episode` and `create_briefing_note`, although the first two said a signed-in person may omit the author. Those three tools now have a person door: with no author and no namespace, the write is recorded as the verified person (`user:<subject>`), in its own team space, stamped with its own organisation (`memories:storeMemory`, `episodes:storeEpisode` and `briefingNotes:create` take `verifiedPerson`, believed from the service account only). A person with a bound personal agent writes as that agent, by ID, as before. A person naming an agent without its credential is still refused `AGENT_CREDENTIAL_REQUIRED`; another organisation's namespace is still refused. Backend contract version 22 (Convex first, then the MCP).
- **VantagePeers Cloud: an agent-less person connection meets the consent page again when it has an agent to choose.** A refresh never shows consent, so a family minted before the consent page listed the person's own agent stayed agent-less forever. A refresh of an agent-less person family is now refused `invalid_grant` (`agent-choice-pending`, family revoked) when the person has an agent of its own or may create one (organisation admin), unless that family's consent explicitly declined an offered agent (`agentChoiceDeclined`, stamped by `oauth:putPersonCode`, carried by every rotation). A plain member with nothing to choose, and a family bound to an agent, refresh unchanged.
- **VantagePeers Cloud: `whoami` names the agent and the workspace on every seat.** Additive top-level fields `agent_name` and `agent_status` beside `agent_id`, `default_write_namespace` and `writableNamespaces`; `agent_status` is one plain sentence naming the fixing step when no agent is bound, `null` otherwise.
- **VantagePeers Cloud: tool text says what the server does.** A write tool a person without an agent cannot call now says so in its description (derived from its declaration), and its `PERSON_NO_HUMAN_DOOR` refusal names the step (reconnect, choose an agent on the consent page). The namespace of `recall`, `text_search`, `hybrid_search`, `list_episodes`, `search_episodes_*` and `list_memories` says it is required for every session except the fleet master. Pinned against the server's behaviour by the client seat matrix (`mcp-server/test/client-seat-matrix.test.ts`, every listed tool x three seats; `node scripts/client-seat-matrix.mjs --out <md> [--live]`).
