- **A person writes in its own space without being told which one.** A signed-in person (claude.ai, OAuth person token, scope team-member) asked to "remember" something had its `store_memory` refused for namespace `global` with a text naming no writable namespace, so the model asked the human. `store_memory` and `store_episode` now take an optional `namespace`: omitted, a person writes in its single write prefix `team/<org>` and a seat in its own `orchestrator/<agent ID>`; master and any session without a single natural namespace are refused with the writable list. Every namespace write refusal now ends with `Writable namespaces (and their sub-namespaces): ...` and, when one exists, the default. `whoami` gains `writableNamespaces` and `default_write_namespace` (optional in its outputSchema, so clients holding the old schema still validate). The default is chosen only among namespaces the write check already admits and is passed through it: no grant changes. MCP-only; no Convex function or argument changes, backend contract untouched.
