- **MCP server (Cloud): master standing, tenant comparison and the kb-ingest gate are read through `@vantageos/cloud-identity`; the name allow-list helper is gone (identity-by-ID plan, batch D).** `isMasterScope` (src/auth.ts) now reads the bearer standing with the package's `bearerStanding` (master bearer, local trust, caller) plus the package's `isMasterScope` for the wildcard-profile OAuth token, instead of a local adapter that rebuilt an `OAuthCtx` out of `isMaster` and `fromAllowList`. The org comparisons of `rowVisibleToActorTenant`, `resolveActorFromRequest` (agent credential bound to the principal's org) and `get_bulk_complete_run` use the package's `isRowInTenant` (both sides stated, strictly equal). `verifiedOrgOf`, `unresolvedOrgDenial`, the `store_document_chunked` / `soft_delete_document` gate and the bulk-run tenant gate no longer read `isMaster`. `isInAllowList` is removed from `normalizeOrchestratorId.ts` (it admitted a name against a list of names and read `*` as everyone; no source used it). The person writer-role gate forwards the verified `orgRole` claim unconditionally and the Convex door decides. No grant is withheld or widened.
