- **Prod-write guard: a Convex write whose URL is assembled at runtime is judged on its action and its target.** `enforce-pi-authorization-before-prod-deploy.py` matched only a literal `https://<name>.convex.cloud/api/mutation` in the command text, so `python3 -c` with `os.environ["CONVEX_URL"] + "/api/mutation"`, an f-string, a variable host (`H=...; curl "$H/api/mutation"`), `urljoin`, and `node -e` with `process.env.CONVEX_URL + '/api/mutation'` were all allowed. The action is now decided by `runtime_write_vector()` in `.claude/hooks/_lib/command_predicate.py` (an HTTP client or interpreter that reaches a Convex surface and writes). The target is resolved from what the station can name: a literal host, a `CONVEX_*URL` variable (inline or in the environment), the prod name, or the dev name in `CONVEX_DEPLOYMENT`. A write that does not resolve to dev is refused, and a write provably to dev passes. A dev deploy key or a read-only marker cannot excuse a runtime write on the same line.
