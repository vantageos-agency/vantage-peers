- **The two PR guards judge the real argv, so a wrapper cannot hide `gh pr merge` or `gh pr create` (task k176rfvfe6wbd9ycf9ekevdpv18jxphr).** `enforce-pi-authorization-before-pr-merge` and `enforce-pr-opened-via-skill` decided on a regex over the quote-stripped command line, so `bash -c 'gh pr merge 1 ...'`, `sh -c`, `zsh -c`, `eval '...'`, `env -S '...'`, a quoted `;` or `&&` chain inside a payload and a heredoc fed to a shell all exited 0 (17 wrapper poles measured on the unchanged tree). Both now decide through `scan_invocations` in `.claude/hooks/_lib/command_predicate.py`, the same shared probe the deploy guards use. A payload the probe cannot read (a shell variable as the command head, or `eval` / `bash -c` of one) is refused with a named reason and never allowed. Pinned by `.claude/hooks/tests/test_pr_guards_wrapper_class.py` (RED at 53742fb0: 17 failed; GREEN at 9ce4c75d, Boat: full hook suite 2419 passed, rc 0). Mutants that neuter the recursion, the heredoc handling, or the fail-closed branch each redden the wrapper poles.
