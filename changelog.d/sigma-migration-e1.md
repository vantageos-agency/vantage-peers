- **`resolveAgentRef`, the single entry for turning an agent reference into an agent row (VantagePeers Cloud, migration step E1).** A helper in `convex/lib/agentIdentity.ts` takes an agent ID, a label, or both. An ID is proved against the caller's verified organisation by its permanent ID (an agent of another organisation, an unknown ID and a retired agent are refused, for reads too); an ID plus a label that is not that agent's label is refused `AGENT_IDENTITY_MISMATCH` with `reason: "id-label-mismatch"`; a label alone behaves exactly as before and writes one `LABEL_ONLY_DOOR` log line `{ door, arg }` (no label value) so the contract decision rests on a count. No door calls it yet, no public argument is added, no contract bump. Pinned by `convex/__tests__/resolveAgentRef.test.ts`; plan `analysis/labels-to-agent-ids-migration-plan-2026-11-01.md` section 6 now carries the operator rulings and the corrected MCP door count (60 of 70).
