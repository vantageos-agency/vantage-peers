section: Changed
---
- **Client scope profiles moved from code to data; `whoami` returns an opaque stable caller id.** `oauth:seedDefaultProfiles` now seeds only the generic profiles (`master`, `client-generic`, `public-readonly`); client profiles are rows of `oauth_scope_profiles`, seeded by the operator migration `migrations/seed_client_scope_profiles:seedClientScopeProfiles` (audit-first: dry-run by default, `apply: true` inserts missing rows, `overwriteDrift: true` patches drift, every write audited; refuses generic ids, `global`/`*` prefixes, wildcard senders and `selfRegistrable`). The two one-shot client migrations were removed. No client name remains in non-test `convex/` or `mcp-server/src`. The MCP tool `whoami` declares an `outputSchema` and adds `caller_id` (HMAC of issuer + subject under a server secret, never the raw Clerk id or agent name), `org_slug`, `role`, `acting_name`, plus `_meta["openai/profile"]`. Server secret: a dedicated `WHOAMI_ID_SECRET` of at least 32 characters; there is no fallback to any other secret (a derived key is a public function of its parent, so a fallback would let an id holder test candidate master secrets offline). `caller_id` is `null` when it is unset or shorter than 32. Evidence: `convex/__tests__/clientScopeProfilesAreData.test.ts` 15/15, `mcp-server/test/whoami-opaque-id.test.ts`.
