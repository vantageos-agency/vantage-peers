- **Rows without a permanent org ID can be counted and backfilled before the slug-class refusal ships.** New internal `migrations/clerkOrgIdCoverage:count` (read-only, counts only) and `migrations/clerkOrgIdCoverage:backfill` (dry run by default, idempotent) for `oauth_scope_profiles` and `tasks`. A row is filled only when its slug names exactly one active mapping that carries an ID; every other row is left untouched and listed by `_id` with a reason count, never guessed, and an existing `clerkOrgId` is never overwritten. A source sweep (`convex/__tests__/clerkOrgIdInsertSweep.test.ts`) pins that every insert of a task or scope-profile row stamps the ID, bar the declared fleet/catalog sites. Evidence: `convex/__tests__/clerkOrgIdCoverage.test.ts` 10/10, red 10/10 on the previous head.
