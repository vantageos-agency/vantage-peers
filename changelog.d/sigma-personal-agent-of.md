- **Cloud: a person token (the claude.ai connector) acts as the agent its person designates (task k17ee3efn6xz4zpapcg68sgvnh8h43gt).** New optional column `agents.personalAgentOf` (a Clerk `user_...` ID) with index `by_personal_agent_of` (`personalAgentOf`, `orgSlug`), written only by the new internal mutation `agents:setPersonalAgentOf` (set, or clear with `personId: null`; `PERSONAL_AGENT_PERSON_ID_INVALID`, `PERSONAL_AGENT_REASON_REQUIRED`, `AGENT_NOT_FOUND`, `AGENT_INACTIVE`, `PERSONAL_AGENT_SERVICE_ACCOUNT`, `PERSONAL_AGENT_CONFLICT` unless `replace: true`, `PERSONAL_AGENT_AMBIGUOUS` when another active agent of the same org already designates the person; every check runs before any write). `oauth:getAccessTokenByHash` returns `personalAgent` (`{ agentId, orgId, agentName }` or `null`), decided by `@vantageos/cloud-identity` `resolvePersonalAgent`: a person token in org O acts as the agent only when EXACTLY ONE active agent of O designates that person; none, only inactive, or several leave the person as the person, an agent of another org is neither selected nor counted, and a resolution that fails (inactive org, unreadable agent) is refused `RBAC_DENIED` rather than turned into "the person". The MCP bearer middleware folds the `personalAgent` into `actor`, the shape a person that presented an agent credential already has, so acting-name binding, `verifiedActor` and whoami take their existing path; the writer-role gate is unchanged and an explicit agent credential still replaces it. No new Convex function called by the MCP, no new argument: `MCP_CALLED_FUNCTIONS` and the contract version do not move. ROLLOUT: Convex first, the MCP last (`.claude/rules/railway-mcp-redeploy.md`); an MCP shipped before Convex simply never sees the field. The `@vantageos/cloud-identity` dependency must be bumped to the release carrying `resolvePersonalAgent` before this merges. No MCP tool by design (operator door, like `agents:setAgentOwner`). Tests: `convex/__tests__/personalAgentOf.test.ts` (15), `mcp-server/test/personal-agent-actor.test.ts` (4), `mcp-server/test/personal-agent-bearer.test.ts` (4). Doc: `docs/cloud/personal-agent.md`.
