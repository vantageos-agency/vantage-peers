section: Added
---
- **Debate room backend: a tenant-scoped, turn-ordered room where agents and people answer one at a time.** New tables `debateTemplates`, `debateSettings`, `debateRooms` and `debateTurns`, and the `convex/debate.ts` doors (`createRoom`, `getRoom`, `postTurn`, `closeRoom`, template and settings upsert/list). Participants, order, wording and every limit are data read from the room's frozen template and settings copies; the functions hold no participant name or limit constant. A post is judged against the credential-derived caller (a `verifiedActor` agent, or a verified person), never a name in an argument: a non-participant is refused `not_a_participant`, an out-of-turn post `not_your_turn`, and a stale, empty or over-long post `stale_turn` / `empty` / `too_long`, each refusal written as a `refused` turn row up to the room's cap. `debateTurns` has one inserting statement (`appendTurn`). Two new MCP tools, `debate_post_turn` and `debate_get_room`, are added to `MCP_CALLED_FUNCTIONS` and to the backend manifest, so the MCP boot check requires `debate:getRoom` and `debate:postTurn` on the backend. Deploy order is Convex first, MCP last. `workDuringTurn` is reported `could_not_judge` for an agent turn: `tasks` has no index by creator.
- **Debate room: a seat is named and admitted by agent ID, the dashboard doors are session-only, and the room's data is bounded.** An agent seat of a template carries the `agentId` of the agent that sits there (no channel, no name); `upsertTemplate` and `createRoom` have the package judge each seat (an active agent of the caller's own organisation, by the seat's ID), the room freezes the template with those IDs, `participantOf` compares IDs only, and `deliverTurn` reads the agent's row by that ID for the address its message goes to (a renamed agent keeps its seat; a different agent with the same name has none). `getSettings`, `upsertSettings`, `listTemplates`, `upsertTemplate`, `createRoom` and `closeRoom` are session-only person doors resolved by `resolveCallerFromClaims` over the ID-keyed org adapters (an administrator is proven by `assertOrgAdmin`, a room's organisation by `assertTargetBelongsTo`, the writer role by `resolveWriterRole`); `closeRoom` no longer accepts a `verifiedActor` (an agent never closes a room). `getRoom` and `postTurn` serve people and agents; the fleet service account is refused (`no-credential`) unless it carries a `verifiedActor`. A `postTurn` by a person is held to the writer role; the `not_a_participant` refusal returns the caller's own `turnSeq`, never the room's. A relayed answer is indented on every line terminator (CR, VT, FF, NEL, LS, PS included). Two seats naming the same person or agent are refused. New `debateSettings` fields `maxLabelChars`, `maxTurnInstructionChars` and `maxActiveRooms` cap the template's free text and the rooms an organisation holds open (index `debateRooms.by_tenantOrgId_and_status`); settings whose largest transcript exceeds the 2000-row read bound are refused, and a room read past it raises `DEBATE_TRANSCRIPT_TOO_LARGE` instead of dropping the newest turns. `orgByIdPrincipalLookups` also answers `agentById` (one keyed read of the agent row, stamped org ID).
