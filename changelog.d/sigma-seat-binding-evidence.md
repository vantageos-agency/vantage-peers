- **`migrations/seat_binding_inventory:bindingEvidence`, a read-only internal query that says which agent each unbound seat profile stands for, from data alone.** Given up to 20 `profileIds` it reports, per profile, its `clerkOrgId`, its live seat-token count, the distinct `agentId` stamped on the profile's own seat tokens (live, and the non-revoked lineage), and for each such agent its `clerkOrgId`, `isActive` and whether it is the profile's organisation (`sameOrg`, by stored ID). The verdict is `bindable` (exactly one stamped agent, active, same organisation), `ambiguous`, `noEvidence`, `crossOrg`, `inactive`, plus `dangling`, `orgUnknown` and `profileNotFound`. No label is compared; the agent name is returned for the operator to read only. Person tokens are ignored (they reuse `agentId` for the person's own choice). Reads are bounded (default 500 per table per profile, `limit` up to 2000) with `truncated` flags. The prod runner allow-list gains this line and `run oauth:bindScopeProfileAgent`, the existing internal door that binds an agent to a profile by ID.
